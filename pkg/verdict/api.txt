package verdict // import "github.com/stainless-code/verdict/pkg/verdict"

Package verdict is the public Go facade over the review core services.

Experimental: the Go API may change in a minor release before 1.0; pin a version
if you embed. The stable contract is the binary's --json envelope plus the
published JSON Schemas (schema_version "1"): the core owns every behavior,
this package only converts typed requests and responses.

Bundle files resolve from the process working directory, exactly like the CLI:
call from (or change into) the checkout that carries .verdict/. Options.Dir
anchors tool-version and provenance lookups to that checkout. Methods are
context-first, never call os.Exit, and never touch process stdio: human lines
and warnings flow through Options.Progress.

Distribution surfaces (install, upgrade, skill) stay CLI-only on purpose and are
not exposed here.

TYPES

type AdoptRequest struct {
	Invocation
	From string
}
    AdoptRequest copies findings from a local bundle into the target bundle.

type AdoptResponse struct {
	Outcome
	Human string
}
    AdoptResponse carries the handoff summary and the human line.

type Artifact struct {
	Path    string
	Content []byte
}
    Artifact is one rendered output file. The service returns bytes; writing
    them is the caller's decision.

type CalibrateRequest struct {
	Invocation
	Reactions      bool
	ReactionReason string
	Probe          bool
	Specs          []string
	JudgeFile      string
}
    CalibrateRequest carries the calibration options: offline probe or live
    ground-truth join.

type CheckResult = recordcore.CheckResult
    CheckResult is CheckReview's output: every problem in document order,
    the overflow past the 50-problem cap, and the clean-run summary.

func CheckReview(review []byte, diff string) CheckResult
    CheckReview validates a review.json against a unified diff. It is pure:
    it reads no store, writes nothing, and collects every problem instead of
    stopping at the first.

type CheckTreeRequest struct {
	Invocation
	Expect string
}
    CheckTreeRequest gates on a clean git worktree.

type CheckTreeResponse struct {
	Outcome
	Exit int
}
    CheckTreeResponse carries the gate outcome and process exit code.

type Client struct {
	// Has unexported fields.
}
    Client runs review operations in-process. It owns no behavior: every method
    converts a typed request, calls one core service, and converts the typed
    response back.

func New(o Options) *Client
    New builds a Client. The zero Options yields a usable client with the wall
    clock, no environment, discarded progress, and the real command runner.

func (c *Client) Adopt(ctx context.Context, req *AdoptRequest) (*AdoptResponse, error)
    Adopt copies findings from a local bundle into the target PR bundle.

func (c *Client) Calibrate(ctx context.Context, req *CalibrateRequest) (*Result, error)
    Calibrate compares stored findings against ground truth.

func (c *Client) CheckTree(ctx context.Context, req *CheckTreeRequest) (*CheckTreeResponse, error)
    CheckTree gates on a clean git worktree. A not-a-repo checkout returns a
    typed refusal, not a response.

func (c *Client) Close() error
    Close releases client resources. It is a no-op today, kept so embedding code
    never needs a second revision when a resource appears.

func (c *Client) Config(ctx context.Context, req *ConfigRequest) (*ConfigResponse, error)
    Config explains the stored effective policy (--explain) or previews a
    proposed file with current settings and environment (--preview). It makes
    no live calls and no writes, and never approves. Resolving the repository
    root runs one `git rev-parse` probe through the environment, not through
    an injected Commander, so a caller that sandboxes execution must cover that
    probe too.

func (c *Client) Doctor(ctx context.Context, req *DoctorRequest) (*DoctorResponse, error)
    Doctor preflights one code host's CLI and auth, git, and storage, and
    reports health.

func (c *Client) Fetch(ctx context.Context, req *FetchRequest) (*Result, error)
    Fetch fetches a pull request into .verdict/state/<pr>.

func (c *Client) FetchLocal(ctx context.Context, req *FetchLocalRequest) (*Result, error)
    FetchLocal fetches a local git diff into .verdict/state/local-<name>.

func (c *Client) Fix(ctx context.Context, req *FixRequest) (*Outcome, error)
    Fix runs one bounded fix pass over an inline finding (or reports completion
    when nothing is actionable).

func (c *Client) Gate(ctx context.Context, req *GateRequest) (*GateResponse, error)
    Gate runs the composed CI gate: findings at-or-above MaxSeverity,
    a completed post for the fetched HEAD (RequireHead), the stored
    diff-coverage receipt for that HEAD (Coverage, default require), and live
    unresolved threads (Live, default auto). At least one dimension is required:
    Live and Coverage alone only set postures, so an empty request is a refusal.
    It never posts, merges, or writes a store.

func (c *Client) Index(ctx context.Context, req *IndexRequest) (*IndexResponse, error)
    Index runs one index query. The MCP tool serves callers and status only;
    this method forwards every query, build and prune included.

func (c *Client) Init(ctx context.Context, req *InitRequest) (*InitResponse, error)
    Init scaffolds .verdict control files from a style preset.

func (c *Client) Learn(ctx context.Context, req *LearnRequest) (*Outcome, error)
    Learn reads or updates the local structured knowledge base.

func (c *Client) Next(ctx context.Context, req *NextRequest) (*NextResponse, error)
    Next returns the top actionable finding for the bundle.

func (c *Client) Pack(ctx context.Context, req *PackRequest) (*PackResponse, error)
    Pack lists the built-in, org, and repo lens packs with their layer, source,
    hash, and declared ids. It makes no live calls and writes nothing.

func (c *Client) Post(ctx context.Context, req *PostRequest) (*Result, error)
    Post submits the review payload; DryRun renders without submitting.

func (c *Client) Ready(ctx context.Context, req *ReadyRequest) (*ReadyResponse, error)
    Ready reports merge readiness (checks, threads, draft/conflict).

func (c *Client) Record(ctx context.Context, req *RecordRequest) (*Result, error)
    Record validates and merges a local review.json into the stores.

func (c *Client) Report(ctx context.Context, req *ReportRequest) (*ReportResponse, error)
    Report renders the offline review report for the bundle.

func (c *Client) Show(ctx context.Context, req *ShowRequest) (*ShowResponse, error)
    Show returns one full finding record by signature or unique prefix.

func (c *Client) Threads(ctx context.Context, req *ThreadsRequest) (*ThreadsResponse, error)
    Threads re-reads one provider's review conversations and rewrites only
    .verdict/state/<pr>/threads.json, or with Resolve closes the selected
    threads and writes threads-resolve.json. Human progress streams through the
    Options.Progress observer.

func (c *Client) Trend(ctx context.Context, req *TrendRequest) (*TrendResponse, error)
    Trend rolls up review outcomes across fetched bundles.

func (c *Client) Triage(ctx context.Context, req *TriageRequest) (*TriageResponse, error)
    Triage flips one finding's status, or previews the flip with DryRun.

func (c *Client) Verify(ctx context.Context, req *VerifyRequest) (*VerifyResponse, error)
    Verify runs the recorded verifyCmd with the watchdog and records proof.

type Command struct {
	Argv  []string
	Stdin io.Reader
	Dir   string
	Env   []string
}
    Command is one spawned process: argv, stdin, environment, and the working
    directory it must run in. Dir is empty when the child inherits the caller's
    working directory; deep validation sets it to the canonical reviewed root.

type CommandResult struct {
	Stdout   string
	Stderr   string
	ExitCode int
	TimedOut bool
	Decoy    bool
}
    CommandResult is one completed process: captured streams plus wait status.

type Commander interface {
	Run(ctx context.Context, cmd *Command) (CommandResult, error)
}
    Commander runs one process to completion. The production client shells out
    to the real gh/git; tests inject a scripted Commander.

	Invocation

	Explain bool
	Preview bool

    must be set; File names the proposed file for preview.

type ConfigResponse struct {

    ConfigResponse carries the read-only policy surface: envelope fields plus

type GateDimension struct {
	Count              *int
	ID, Status, Detail string
}
    GateDimension is one gate dimension's verdict and its own tally. Count leads
    so the struct scans no pointer bytes; the wire key order is fixed in the
    JSON builder, not here.

type GateRequest struct {
	Invocation
	MaxSeverity string
	Live        string
	Coverage    string
	RequireHead bool
}
    GateRequest composes the CI gate dimensions. An empty MaxSeverity skips the
    findings tier; Live stays empty for the auto posture. Coverage stays empty
    for the `require` posture, the CLI's default: an absent or partial stored
    diff-coverage receipt fails the gate, and "warn" reports it without failing.

type GateResponse struct {
	Result
	Dimensions []GateDimension
	Passed     bool
}
    GateResponse carries the composed gate verdict. A failed gate is a verdict,
    not a refusal: the error stays nil and Passed is false.

type IndexRequest struct {
	Query, Symbol, Path, From, At, Since string
	Limit, Commits, MinCount             int

    IndexRequest queries the local code index. Query is any index subcommand
    — callers, status, tests-for, co-changed, owners, build, or prune;
    Symbol is the caller or tests-for symbol, Path the tests-for, co-changed,
    or owners path, At names a tree or ref, From overrides the checkout, Since,
    Commits, and MinCount bound the co-change window, and Limit bounds rows.

	// provenance lookups; bundle files still resolve from the process

type Problem = recordcore.Problem
    Problem is one review-input problem: its JSONPath, code, level, message,
    exact fix, and an optional example of the accepted shape.

func NormalizeReview(review []byte) ([]byte, []Problem)
    NormalizeReview repairs the mechanical shapes weak models emit — a
    whole-document code fence, prose around the object, scalars where a string
    array belongs, key aliases, enum synonyms and case, and trivial bytes — and
    returns the normalized document plus one warning per rewrite. It is pure,
    deterministic, and idempotent. It never invents or rewrites prose, and a
    document it cannot recover comes back unchanged for CheckReview to refuse.

type Progress interface {
	Human(line string)
	Warn(msg string)
	Diag(line string)
}
    Progress observes human-facing lines. It mirrors the core observer seam so
    no core type appears in a public signature; a nil Progress discards.

type RecordRequest struct {
	Invocation
	CostPanel []string
	DryRun    bool
	Strict    bool
	CostNames bool
}
    RecordRequest merges a local review.json into the findings store.
    DryRun reports what would be recorded and writes nothing. Strict promotes
    warning-only input to a refusal. CostNames asks for the cost-name repair,
    naming models[] entries from CostPanel in the order the panel ran (an empty
    panel with CostNames set reads the panel the bundle pinned).

type VerifyRequest struct {
	Invocation
	Timeout string
	Group   string
	Command string
	Env     []string
	// Sandbox wraps the command in the enforced Linux bwrap sandbox: no
	// network, empty credential dirs, a writable reviewed root, and a private
	// /tmp. The call refuses with sandbox-unavailable when the host cannot
	// enforce it instead of running unwrapped.
	Sandbox bool
}
    VerifyRequest runs the recorded verifyCmd under the watchdog, or one deep
    plan group's explicit command when Group and Command are both set.

type VerifyResponse struct {
	Result
	Exit     int
	PatchDir string
	TimedOut bool
	Tail     string
	Group    string // deep validation: the group the receipt certifies
	Head     string // deep validation: the head the command ran on
	Receipt  string // deep validation: the recorded receipt path
}
    VerifyResponse carries the verify outcome and the recorded proof.
