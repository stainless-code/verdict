Copilot code review, Cursor's Bugbot and Agent Review, Greptile, Graphite, Macroscope
and Pullfrog, plus a long tail of SaaS reviewers and one close open-source project, and
the status quo of human-only review.

Every vendor row above is a hosted component with seats, credits, an org fee, a
per-review credit or a usage meter. Verdict has none of those. It does one job: fetch,
review, post, stop. Setup is one binary, the blast radius is one post, and the model is
your choice. In exchange it skips the hosted features in the "Where they win" column.

## Local review is no longer the wedge

Most of the field has a local story now, so it is not the difference. CodeRabbit's CLI
reviews tracked, staged and unstaged changes, with `--uncommitted` to narrow it and
`--include-untracked` to widen it. Greptile's `greptile review` reviews committed branch
changes against a base and skips uncommitted work. Cursor runs Agent Review and
`/review-bugbot` over local changes before the push, and Copilot code review reviews
uncommitted changes in VS Code. The Macroscope CLI reviews a frozen snapshot that
includes work in progress. Each one wants its account signed in, and each bills the
review on its own meter.

What Verdict claims instead is narrower, and checkable: the review target is a plain
bundle on disk. `fetch` writes `.verdict/state/<pr>/` with `PR.json`, and `fetch-local` writes
`.verdict/state/local-<name>/` with `source.json`; both carry `full.diff`, `toc.txt` and
`roles.txt`, and nothing stays running. A local bundle needs no host login, no app
install and no account. The diff goes only to the model your agent runs, which you pick.
The same files feed `report --check` in CI and `post` on GitHub, so the gate and the
review read one artifact.

## The long tail

The long tail is not uniform: Qodo meters credits (`$0.012` each; Pro Team `$30`/mo buys
roughly 18 reviews and packs scale to 20,000 credits, roughly 144) and also publishes
`PR-Agent`, an MIT reviewer with 14k stars; Sourcery sells seats (`$12–$24` per dev/mo
annual) and puts self-hosting, SSO and bring-your-own keys on Enterprise; Ellipsis runs
the harness for you at tokens plus 10%. The closest open-source project is proval, AGPL-3.0, self-hosted, bring your own
model including a local one, for GitLab, Forgejo and GitHub, but it answers "local"
with a Docker Compose service, a dashboard and an encryption key, where Verdict answers
with one binary and no service.

## Complements, not competitors

clawpatch (machine-checked fix-to-revalidate loops for whole-repo campaigns) and pstack
(verification culture and multi-model endurance) shaped this skill's discipline. They
solve different problems and can run after Verdict posts.

## Lineage

Verdict's review core descends from Pullfrog's open-source action: the review prompt,
not its harness wrapping. It is credited in
[NOTICE](https://github.com/stainless-code/verdict/blob/main/NOTICE.md). The review
craft is shared on purpose. The disagreement is the meter.
