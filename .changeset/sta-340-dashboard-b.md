`verdict dashboard` is now live and complete. Five more tabs join the Overview and Queue, each backed by one read from the same query layer `serve` uses: **Detail** (`3`: one bundle's gate, verdict counts, and findings with severity, status, the rigor rung, and the quote check), **Diff** (`4`: lanes in risk order and every hunk with anchored findings marked; `u` switches to side by side from 100 columns), **Compare** (`5`: new, persisting, resolved, and not-reviewed findings against a baseline picked with `b`), **Cost** (`6`), and **Precision** (`7`), with `Tab` cycling their groupings. The view recomposes as bundles change (`--interval 2s`, `--sweep 60s`, `--no-watch` to turn it off); composition runs beside the key loop, so keys never wait on a slow compose and a burst of changes costs one compose. Keys: `j`/`k`, `g`/`G`, Ctrl-D/Ctrl-U, `Enter`, `Esc`, `/` search, `r` refresh, `y` copy the finding's fix prompt through OSC 52 (never a subprocess), and `?` for help. `dashboard <owner/repo>` narrows the portfolio to one repository, `--check` sets the gate tier, and `--once --tab <name>` prints any tab as plain text. A crash in a compose restores the terminal like any other exit.
