`verdict ingest --from sarif <file|->` imports an OASIS SARIF 2.1.0 document from any static analyzer — Semgrep, Opengrep, CodeQL, golangci-lint, Ruff, Trivy, or `verdict report --sarif` — from a file path or stdin, under the same 8 MiB cap. The flag names a format, never a vendor; `--sarif <file|->` keeps its older spelling, and `--from` with any other format refuses `bad-from`. One source per call: combining `--from` with `--sarif`, repeating either flag, an empty `--from`, a bare `<file|->` without `--from`, and an unknown dash flag are usage errors instead of silently picking a source. Every result is graded against the bundle's pinned `full.diff` and `hunks.tsv` instead of the scanner's claim: the diff line becomes the finding's `quote`, an anchored finding grades `rigor: "pointed"` (never `walked`/`ran`/`reproduced`/`"verified"`), and a reported `region.snippet.text` that disagrees with that line is skipped rather than re-pointed. A result with no physical location, no usable line, a path outside the repository, a path the diff names twice, or a line outside the changed hunks is published in the new `data.skipped[]` with a typed reason (`no-location`, `invalid-line`, `path-escapes-repo`, `out-of-diff`, `ambiguous-path`, `snippet-mismatch`) and never dropped silently or stored at line 0. URIs normalize by keeping a path-only `file:` reference, turning Windows separators into `/`, and decoding percent escapes once, while absolute paths, drive paths, colons, invalid UTF-8, raw or encoded `..` traversal, and every authority-bearing `file://` reference (RFC 8089: `file:///abs`, `file://localhost/etc/passwd`, `file://host/share/x`) stay refused. Results dedupe by the stable finding signature and by `(tool, fingerprint)` both within one document and against the store, a trusted exclusion path stays withheld under `exclusion`, and a model finding is preserved. `report --sarif` now carries the original `tool`, `rule_id`, and `fingerprint` under `properties`, so its export re-ingests as the same findings — unchanged, not duplicated.
