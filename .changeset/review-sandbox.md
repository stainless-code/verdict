**Security:** every review launch now also runs in the host's OS sandbox (STA-538). `verdict run --agent` finders, cross-checks, repair rounds and drain, and `verdict loop`'s review step, run under `sandbox-exec` with a generated profile on macOS and under `bwrap` on Linux, with the network open so the agent reaches its model API. A review agent can write only its launch's snapshot directory (its working copy and private `TMPDIR`), its own cited state paths (`claude`: `~/.claude`, `~/.claude.json*`, the macOS login keychain and cache; `codex`: `~/.codex`; `opencode`: its XDG data, config, state and cache directories; `pi`: `~/.pi`; each relocation variable honored), and the devices a process needs — no other dotfile in `HOME`, nothing else under `~/.config`, never your checkout — and cannot read the credential table `verify --sandbox` hides, which now also covers glab's `~/.config/glab-cli` and `GLAB_CONFIG_DIR` (for `verify --sandbox` too). Before, an agent tool that took an absolute path could write anywhere you can and read your credentials into review text. `codex` keeps its own `--sandbox workspace-write` sandbox instead, because a nested Seatbelt profile fails on macOS; it confines its writes, but its reads are not confined, and `run` warns so. With no sandbox (Windows, Linux without bubblewrap, a probe that fails), `claude` and `codex` still run with a warning that their reads are not confined, and every other agent refuses the new `review-sandbox-unavailable` code before it starts; `--allow-unsandboxed-review` on `run` and `loop` runs every review launch without the sandbox, warned. A row with no state paths can write only its snapshot and `TMPDIR`, and `run` warns so; an agent you define in prefs declares its own as `agents.<name>.state_locations`. `run --json` reports the posture in `data.sandbox` (`--print` adds the wrapper argv with a `{snapshot}` placeholder), and `loop --print` carries it on each review step in `plan[].sandbox`. A sandboxed launch runs the agent binary verdict resolved by its absolute path. The loop's fix spawn is never sandboxed: editing your checkout is its job.
