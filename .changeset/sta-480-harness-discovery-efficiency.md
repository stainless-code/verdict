`run` now launches discovery read-only. Every finder, opposite-finder cross-check, repair round, and drain launch carries the agent row's own documented tool restrictions, so an external harness cannot spend its budget on builds, tests, and cross-compiles that `verify --sandbox` runs better; file reads and the `review.json`/`verdicts.json`/`drain.replies.json` write stay allowed. Three rows carry the exact documented spelling, each with the primary-source citation: `claude` emits `--disallowedTools=Bash,PowerShell` (the joined form, because the spaced one swallows the directive as a tool name, and both shells because a Windows Claude Code reaches the shell through either), `bob` emits `--disable-tool-groups execute,mcp`, and `pi` emits `--exclude-tools bash,powershell`. Rows whose CLI documents no such flag are launched unchanged. `--allow-shell` restores the row's own tool set, and an operator spelling of the row's override flag after `--` suppresses the restriction instead of duplicating it. `--resume` seals the applied restriction into the launch digest, so a resumed execution that changed it fails closed with `resume-drift`. `verify --sandbox` is untouched.

Chunked fetches now pack related files together. Before the greedy next-fit pack, files are ordered semantically — package directory first (by path segments), then implementation and test pairs by stem (`foo.go` beside `foo_test.go`, `bar.ts` beside `bar.test.ts`, `baz.py` beside `test_baz.py`), then path bytes — so coupled files share a chunk whenever the cap allows. Per-group runs pack one group at a time at that group's own cap and never mix two groups in one chunk. Every file section is still carried byte-identically and the order is deterministic across runs and path separators; `record`'s drift check now compares sections rather than the ordered concatenation, which a regrouped chunk map no longer reproduces, and it reads the same privacy-filtered view the chunk payloads carry, so a withheld section is never drift. Chunk payloads are sliced from the diff the privacy exclusions already filtered, so a withheld section can never leak into `chunk-NN.diff`, and an unterminated final section keeps the diff's own order so no two sections merge.
