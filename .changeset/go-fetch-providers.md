Experimental opt-in Go implementations of `fetch` and `fetch-local`, including
the GitLab, GitCafe, Forgejo, Bitbucket, and Azure providers. `VERDICT_IMPL=go`
dispatches both bundle builders to the compiled binary with byte-identical
bundles, envelopes, hints, and exits, plus the large-PR edge set as structure:
paged file listing past the CLI cap with the provider ceiling noted, the
distinct upstream over-file-count refusal with its recovery hint, and bounded
secondary-rate-limit backoff. The default stays shell, and the parity harness
(`internal/fetch` shell-parity suites) proves byte parity across hosts, flags,
chunking modes, and every written file.
