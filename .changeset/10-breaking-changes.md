**Breaking changes (pre-1.0)**

Package is on `0.x`, so these ship as a minor bump; each one names the step that migrates it.

- **`index blast-radius` truncation shape** — the integer `truncated` count and `depth_truncated` are replaced by the shared boolean receipt (`truncated`, `truncation_reason`, `returned`, `total`, `next_offset`), and a complete result omits the receipt instead of carrying `truncated: false`. _Migrate:_ read `truncation_reason` and `returned`; treat an absent receipt as complete. [Code index](docs/manual.md#code-index) <!-- changesets: typed-truncation.md -->
- **`gate` checks coverage by default** — the new `coverage` dimension fails when the gated HEAD has no receipt, a receipt for another HEAD, no `coverage[]` attestation, or under 100% attested. _Migrate:_ `--coverage warn`, or the SDK `Coverage` field, keeps the old passing behavior while reviews attest nothing. [Gate](docs/manual.md#gate-one-composed-exit-code-for-ci) <!-- changesets: gate-coverage-default.md -->
- **`gate --live` reads every host** — a non-GitHub bundle used to pass the live dimension without reading threads; it now reads the bundle's own host and fails closed when it cannot. _Migrate:_ `--live auto` warns and gates on the local dimensions only. [Gate](docs/manual.md#gate-one-composed-exit-code-for-ci) <!-- changesets: gate-live-all-hosts.md -->
- **Unknown gate tiers refuse** — an unrecognized tier is `bad-flags` on the MCP `report` tool and in `Report.Check`/`Gate.MaxSeverity`, not only on the CLI. _Migrate:_ send a tier from the published set, or omit the field. [Gate](docs/manual.md#gate-one-composed-exit-code-for-ci) <!-- changesets: gate-tier-validation.md -->
- **`verify` child environment is default-deny** — only baseline locale, terminal, shell, XDG, and toolchain names pass, and a secret-shaped name is dropped even when it matches an allowlist prefix. _Migrate:_ list what you need in `.verdict/verify-env` or `--env-allowlist`; dropped names appear in `warnings[]`. [Child environment](docs/manual.md#child-environment-what-inherits-what-is-explicit) <!-- changesets: verify-env-allowlist.md -->
- **`verify` refuses command shapes it used to run** — `wget --remote-name`/`-i`, `curl -K`, `busybox wget`, `pip3 download <url>`, `telnet`, `git archive --remote`, and the rest refuse `verify-networked` in attached and clustered spellings, and a command word built from a variable (`E=rm; $E -rf ./target`, including the braced, quoted, `export`ed, loop, and wrapper spellings) refuses `verify-indirection`. _Migrate:_ write the tool word plainly and rewrite the command to a plain fetch your recipe can run; every refusal keeps its `try:` hint. [Known residuals](docs/manual.md#known-residuals-string-scan-ceiling) <!-- changesets: verify-static-gate-bypasses.md, verify-indirection.md -->
- **`.verify.out` is owner-only** — the verify stream is written `0600` on Unix where it was `0644`, because a command that prints a credential leaves the value in it. _Migrate:_ read it as the user that ran `verify`, or copy the bytes inside that same step; on Windows the file keeps the directory's inherited ACL. [Enforced sandbox](docs/manual.md#enforced-sandbox-verify---sandbox) <!-- changesets: verify-out-owner-only.md -->
- **Bundle paths are guarded** — a bundle name that is not one path element (`a/b`, `..`, `CON`, `x:`) refuses `bad-flags`, and a symlinked bundle root or component refuses before any write, including a link that points inside the repository. _Migrate:_ one plain name per bundle, and a real directory where a link used to work. [Bundle namespace](docs/manual.md#bundle-namespace-core-files-vs-x-) <!-- changesets: bundle-name-guard.md, managed-parent-symlinks.md, write-bundle-symlinks.md -->
- **Provider is inferred from origin** — with no `--provider` flag, an unknown or conflicting origin now refuses `provider-unknown` instead of defaulting to GitHub. _Migrate:_ pass `--provider` explicitly, or keep a plain GitHub origin. [Providers](docs/manual.md#providers-non-github-hosts) <!-- changesets: provider-from-remote.md -->
- **`capabilities` splits, `truncated` widens** — the binding verdict becomes `approve` and `request_changes` with `review_verdicts` kept as the compatibility sum, `unsupported` names each absent capability, and `data.truncated` widens from `boolean` to `boolean | row[]`. _Migrate:_ branch on the two new flags, and narrow `truncated` before you read it as a boolean. [Published schemas](docs/manual.md#published-schemas--drift-rule) <!-- changesets: honest-capabilities.md, provenance-receipt.md -->
- **`pack add` source allowlist** — only `https://host/path` with no userinfo, `ssh://user@host/path`, and `user@host:path` are accepted; anything else refuses before a git call, and a lock row carrying one refuses at `pack list`, `fetch`, `post`, and `record`. _Migrate:_ rewrite the source in one of the three forms. [Lens packs](docs/manual.md#lens-packs) <!-- changesets: pack-source-allowlist.md -->
- **Benchmark cases name their commits** — a real corpus case now requires `provenance.base_sha` and `provenance.head_sha` (40-hex), the two commits the reviewed diff spans, and a bundle stamps the same pair. _Migrate:_ add both commits to every real `case.json`; a case without them fails validation. [Benchmark corpus](docs/benchmark.md) <!-- changesets: bench-real-pilot.md -->
- **Rebuild indexes** — indexes written by the previous scanner over-report callers, so rebuild them. _Migrate:_ `verdict index build --at HEAD`. [Code index](docs/manual.md#code-index) <!-- changesets: index-import-shadow.md -->
