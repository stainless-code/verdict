New `verdict dashboard`: a read-only terminal view of the review portfolio over the same query layer `serve` renders, in the zero-dependency binary. **Overview** (`1`) shows the portfolio totals, the served roots, and every bundle the layer refused; **Queue** (`2`) shows one row per bundle with its counts, model, and head. Totals the layer withholds show `—`, never a smaller number, and a refused bundle keeps its row marked `!`. The live view needs a terminal on stdin and stdout (else it refuses `dashboard-no-tty`, or `dashboard-no-vt` on a Windows console without virtual-terminal support); it redraws only the cells that change, `q`/`Esc` quits, Ctrl-C exits 3, Ctrl-Z suspends on macOS and Linux, and every handled exit restores the screen (a SIGKILL runs no cleanup: recover with `reset` or `stty sane`). `--once` prints one plain-text Overview frame to stdout and exits 0. `--root` reads every repository below a directory through `serve`'s discovery cache. Color is the 16 ANSI colors; `NO_COLOR`/`--color never` keeps attributes only and `TERM=dumb` switches to ASCII glyphs. Text from a stranger has its control characters folded to spaces before it reaches the screen, so it cannot move the cursor or write the clipboard.
