# Offline contract evals

Smoke-grade graders for the doctrine and verb contracts in `SKILL.md` and
the `verdict` binary: exactly-one terminal write, the no-review-note rule,
`--bind` downgrade behavior, and the `--json` envelope shape
(`schema_version: "1"`). They complement calibration (which grades judgment
against live ground truth); these grade contracts against fixtures.

## Run

```sh
./evals/run.sh              # all cases; exits non-zero on any failure
./evals/run.sh --keep       # leave the temp sandbox in place for debugging
EVAL_JOBS=1 ./evals/run.sh  # serial (the old behaviour)
EVAL_JOBS=8 ./evals/run.sh  # cap the parallel batch at 8 cases
```

Cases run concurrently by default, one job per CPU (`getconf
_NPROCESSORS_ONLN`, then `sysctl -n hw.ncpu`, then 4); `EVAL_JOBS=N` overrides
that limit. Every case gets its own sandbox, stub `gh` dir and stub log, so
cases cannot see each other's fixtures or intercept counts. Case output is
buffered and replayed in sorted case order, so a parallel run's report is
deterministic; the final `evals: N passed, M failed, K skipped` line and the
repo-tree-unchanged check are unchanged.

A case that genuinely cannot share the machine can opt out of the batch with
a `# eval: serial` line in its header (first ten lines). Those cases run one
at a time after the parallel batch, and still get their own sandbox.

New cases go in `evals/cases/*.sh` (sourced helper: `evals/lib/common.sh`);
`run.sh` picks up every file there, so no registration step. Results land in
`evals/results/summary.json`, which is gitignored (`evals/.gitignore`) —
the harness asserts the run, the repo keeps no trace of it.

### Pass, fail, and skip are three different things

A leg that did not run proves nothing, so it is never graded as a pass. A case
that cannot run a leg calls `skip "<reason>"` (one leg) or `skip_case
"<reason>"` (the whole case); `eval_end` then exits 77, `run.sh` reports `SKIP
<case>` and tallies it separately, and **the run fails** with `evals FAIL: N
case(s) skipped` unless `EVAL_ALLOW_SKIP=1` accepts the gap:

```sh
EVAL_ALLOW_SKIP=1 ./evals/run.sh   # accept skipped legs (they still print SKIP)
```

The same rule governs the shared assertions: an absence is stated with
`assert_file_nogrep` (the file must exist and be non-empty) or
`assert_stream_nogrep` (a stream the harness or the case owns; it must exist,
but may be empty), never with a bare `! grep -q`, which passes when the file
was never written. `absence-guard` grades that convention and the shared
helper vocabulary against this suite's own sources.

## Implementation (the built binary)

Every case invokes one CLI: the built `verdict` binary at `$EVAL_CLI`
(`make evals` builds `bin/verdict` first, then runs the suite; `make build`
alone writes `bin/verdict`, gitignored). `evals/run.sh` and `evals/one.sh`
default `EVAL_CLI` to `$ROOT/bin/verdict` and fail fast when it is missing
or not executable, so a case never silently grades nothing. No `VERDICT_IMPL`
switch remains: the binary owns every verb.

CI runs the suite on macOS and Ubuntu, plus a Go gate (`make ci-go`:
gofmt, vet, mod verify, `go test -race`, govulncheck, golangci-lint with
the repo config) and a Windows build-and-test job. Any failing leg fails
the build.

## Hermeticity (how "no network" is proved, not promised)

- Fixtures are crafted files (`PR.json` state OPEN + one-hunk diff) written
  into a per-case `mktemp` sandbox that `run.sh` uses as the CLI cwd; the
  repo's own `.review/` is never touched. Each case starts from a fresh,
  empty sandbox (no fixture or repo state inherited from a sibling).
- `run.sh` puts a network-dead `gh` stub first on `PATH` in every case: every
  `gh` call the CLI attempts (live-SHA lookup, authorship check) fails fast
  into the script's existing warn-and-proceed path, and each interception is
  logged to that case's stub log. The tally line sums the per-case logs and
  reports the intercept count — zero real calls by construction.
- Cases that need scratch outside the sandbox give it a per-run name (for
  example the verify family's `/tmp/...$$` probe dirs), so two concurrent
  copies cannot clobber each other. A case that cannot be isolated that way
  should carry the `# eval: serial` header instead.
- After the cases, `run.sh` diffs `git status --short` before/after and fails
  the run if the tree moved; fixtures are deleted unless `--keep`.
