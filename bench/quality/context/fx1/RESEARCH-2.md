## Open Questions, Conflicts & Special Notes

1. **Warp (`warp`) vs Legacy Oz CLI (`oz`):**
   - `warp` (`https://docs.warp.dev/agents/cli/reference.md`) only accepts `--api-key`, `--auto-approve`, `--clear-provider-api-key`, `--help`, `--resume`, `--set-provider-api-key`, and `--version` — it is interactive-only and has **no** headless prompt mode.
   - However, Warp also distributes the **legacy `oz` CLI** (formerly `warp-cli`, [oz-cli.md](https://docs.warp.dev/agents/cli/oz-cli.md)): `oz agent run --prompt "<prompt>" --model <MODEL_ID>` (`brew install --cask oz`, `WARP_API_KEY`, `--profile <ID>` for tool permissions). Because `oz` is a separate legacy binary rather than `warp`, `warp` stays `no` in Step 1 (`oz` would rate `NEEDS-FIELD (prompt flag)` if added as a separate binary).
2. **Shut-down / Unmaintained / Removed CLIs:**
   - **iFlow CLI (`iflow`):** `https://platform.iflow.cn/en/cli/configuration/settings` states `"iFlow CLI will officially shut down on April 17, 2026 (Beijing Time). Please migrate to Qoder."` Marked `NO` for Verdict fit.
   - **Tabnine CLI (`tabnine` / `tabnine-legacy`):** Deprecated after December 31, 2026; transitioning to Tabnine Plugin for OpenCode (`docs.tabnine.com`).
   - **OpenHands CLI (`openhands`):** `OpenHands/OpenHands-CLI` README states `"This project is no longer actively maintained."`
   - **Reasonix (`reasonix`):** `esengine/DeepSeek-Reasonix` README states `"Reasonix is no longer maintained as of 2026-11-12."`
   - **Pochi (`pochi`):** Removed `packages/cli` and CLI documentation in `TabbyML/pochi` PR #2037 (2026-10-27), though stale `@getpochi/cli@0.6.21` remains on npm.
   - **Alibaba Lingma (`lingma`):** Alibaba Cloud Lingma skill docs now banner migration to **Qoder CN** (`docs.qoder.cn`).
3. **CLIs without a `--model` flag:**
   - `bob`, `forgecode`, `jazz`, `openhands`, `rovodev`, and `zcode` have no CLI `--model` flag on their headless subcommand/root invocation (models are read from config files/env vars). Verdict can still run them with `ModelFlag: ""` when the user omits `--model`, or reject/warn if `--model` is supplied.
4. **Prompt & Argument Edge Cases:**
   - **Devin (`devin`):** `--print` / `-p [PROMPT]` accepts an optional inline prompt OR positional `[prompt]` after `--` (`devin -p --model <m> -- "<prompt>"`), so it could `FITS` if `Args` ends with `["-p", "--"]`; otherwise `-p` takes `[PROMPT]` as a flag value (`NEEDS-FIELD (prompt flag)`).
   - **Command Code (`cmd`):** Docs warn `"Always wrap your query in quotes. Unquoted multi-word queries cause argument parsing errors."` Meaning `-p [query]` consumes only the argument immediately following `-p` (`NEEDS-FIELD (prompt flag)`).
   - **Jazz (`jazz`):** `jazz run` requires `--agent <id>`, so Verdict's default `Args` must include a configured agent ID (e.g. `["run", "--agent", "default"]`).
   - **Dexto (`dexto`):** `register.ts` defines `-m, --model` directly on `dexto run`, while permission flags (`--permissions-mode full-access` / `--full-access`) are defined on root `program` in `index-main.ts` — verify at runtime whether `--full-access` must precede `run` or can follow `run`.
   - **Junie (`junie`):** `--brave` is explicitly `"Interactive mode only"`; in headless mode, non-workspace edits, build-script edits, and shell executables depend on `~/.junie/allowlist.json`.
   - **Kimi Code CLI (`kimi`):** `env-vars.md` explicitly warns that shell `KIMI_API_KEY`, `ANTHROPIC_API_KEY`, and `OPENAI_API_KEY` are ignored unless referenced via `config.toml` `api_key_env`.
   - **Tinycloud (`tinycloud`):** `@cloudglue/tinycloud` (`tinycloud.sh`) is an agent CLI for video and image work (not a coding agent) and documents only `tinycloud login`, `tinycloud setup`, and an interactive prompt.
