# Shell lens

Dispatch only when the diff changes what a script expands, deletes, or how it
fails. Frame one falsifiable question — which word splitting changes the
target, which failure the pipeline hides, which path can resolve elsewhere —
and give it a short hypothesis label.

Read the changed script and its callers; the on-disk diff is authoritative
scope. Scope the question to at most ~12 files, cite NEW line numbers, and
name the value that makes the command leave its intended target.
