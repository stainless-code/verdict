# TypeScript/JavaScript lens

Dispatch only when the diff changes async control flow, a trust boundary, or
a component lifecycle. Frame one falsifiable question — which rejection is
unobservable, which parsed value reaches a typed field unchecked, which effect
outlives its component — and give it a short hypothesis label.

Read the changed files the dispatch names; the on-disk diff is authoritative
scope. Scope the question to at most ~12 files, cite NEW line numbers, and
quote the code path that makes the failure reachable.
